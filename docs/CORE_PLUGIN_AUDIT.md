# 核心与在线插件分离验收记录（2026-09-09）

## 结论和范围

当前候选符合“核心不包含具体在线平台实现”的源码与构建边界。核心保留通用在线页面、插件管理、
安全投影、媒体调度及能力契约，具体平台 API、登录/续期、取流、音质档位和网关声明由外部插件实现。
这不是把平台代码编进核心后用开关隐藏。也不是宣称所有本地功能都必须外置。

导出采用允许清单和新的 Git 历史，不包含私人平台工程、旧合并平台程序集、私人仓库历史、账号状态、
个人媒体、浏览器配置、构建缓存或签名私钥。公开候选的 C# 和项目文件与当前维护源码逐字节一致；
Web 演示封面/文本仅替换为通用原创示例。具体平台插件不进入此仓库及默认发布目录。

## 已取得证据

- 不含私人实现的独立源码树 restore、Release build（零警告、零错误）和 win-x64 自包含 publish 成功。
- 对主程序及全部随包播放、传输、图片组件进行平台实现/资源/构建输入检查；发布输出无具体平台 DLL。
- 21 项边界正反例通过，能拒绝将平台代码或私有项目链接移入这些通用组件。
- 核心服务、平台宿主、播放宿主、传输、图片测试通过；契约自检工具 89 项断言通过。
- 任意来源 ID、无插件、未配置设置、惰性发现/加载、禁用清理、旧修订、所有权和迟到响应均有合成回归。
- 歌词时钟、播放规划、平台切换、搜索历史/防抖共 21 项逻辑测试通过。
- 实际发布资源的全部六套界面回归通过：插件管理、声明设置、歌单、媒体、播放组件、传输组件。
  覆盖深浅色及 100%/150%/200% 浏览器比例，并包含键盘和减少动画路径；不代表原生 DPI 验收。
- 真实 LibVLC 使用静音、临时生成的 WAV/AVI 验证暂停打开、进度、切换、循环、内存视频帧及音频信息接口。
  此测试没有使用私人音乐、平台账号或用户设置。

## 音质信息

新增可选 IPlaybackAudioInformation，不向既有 IPlaybackSession 增加必需成员。
完整 FLAC 的采样率、位深及声道来自 STREAMINFO；平均码率按去除元数据后的编码字节与样本时长计算，
标签以“≈”区分平均值，详情提供 kHz、bit、ch。其它媒体使用可获得的解码器信息和插件标称值。
缺失字段不推测，不能用 PCM 理论带宽或网络下载速度冒充编码码率。
切歌、关闭和迟到回调不能保留上一首的质量信息。合成 FLAC 测试覆盖大元数据填充不抬高码率及畸形输入。

## 不应扩大解释的边界

这些结果不是全部真实平台账号、地区、音源、Windows DPI/窗口模式及听感的最终验收。
浏览器深浅色和缩放回归不等于真实多显示器 DPI；静音解码不证明扬声器发声或音画同步。
外部插件的在线可用性与平台服务有关，不能由核心离线构建或契约检查保证。
同进程可信插件不是恶意代码沙箱；源码边界检查不是完整安全审计。
图标来源和依赖声明已随源码保留，仍需在公开及二进制发行前完成最终许可和分发核对。

仓库仅按用户授权以私人方式保存，未经用户再次明确确认不得改为公开；本次不发布安装包。
