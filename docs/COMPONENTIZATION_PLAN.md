# 播放器与可选在线插件的边界

本文是公开核心的当前架构与验收约束，不是私人插件的迁移日志或全部功能外置计划。
**具体在线平台必须独立实现；本地播放器不需要变成等待用户安装组件的空壳。**

## 职责与依赖

| 层 | 负责 | 不应包含 |
| --- | --- | --- |
| Auralis 主程序 | 本地曲库、队列、收藏、播放意图、Fluent 页面、Windows 集成、LAN，以及通用插件管理 | 具体平台 ID 分支、API 端点、账号策略、固定音质/网关字段 |
| Platform.Abstractions | 归一化实体、能力接口、错误、短期媒体租约与插件所需服务契约 | 平台实现、播放器窗口或解码器类型 |
| Platform.Host | 清单发现、兼容校验、明确批准后的惰性加载与能力路由 | 内置平台白名单、历史凭据地址或图片域名回退表 |
| 独立在线插件 | 平台 API、认证/续期、取流、平台歌词/评论/媒体扩展及专属设置声明 | 随默认公开核心分发的私人实现；向主 WebView 暴露秘密 |
| 随包播放、传输、图片组件 | 通用解码、播放会话、HTTP 传输、图片读取及生命周期 | 隐藏在通用组件中的平台专属业务 |

主程序只通过公共平台 Host/契约调用在线能力；Host 不反向依赖主程序或具体平台项目。
播放、传输和图片的具体实现有各自组合点，平台 DLL 不负责替换主窗口或接管队列。
平台负责产出归一化数据；核心验证归属、授权和生命周期后，为界面分配不透明句柄。
插件名称、账号入口、设置、搜索来源和媒体扩展入口依据当前注册及能力声明显示，不按已知平台名称猜测。

本地库、LRC 解析与显示、音效、Windows 媒体控制和 LAN 可以内置。
已有播放/传输组件接口和可选导入功能保持，但继续外置本地功能不是在线解耦的完成条件。
图片工厂接口不等于存在用户可导入的图片插件入口；不要把接口化宣传为全部功能可选安装。

## 生命周期和数据所有权

1. 清单发现只读取元数据，不加载 DLL、不创建平台 HTTP 客户端，也不登录账号。
2. 用户导入并明确批准完整修订；新包默认关闭。启用和更新需要重启，活动会话不热替换 DLL。
3. 首次明确能力调用才激活对应已批准、启用且兼容的插件；缺少必填设置时先引导配置。
4. 停用阻止后续调用并撤销凭据访问；清理使用当前会话修订的批准声明，不能用待更新修订猜测账号地址。
5. 取消、切歌、停用和关闭后的迟到结果不得覆盖新页面、恢复已撤销账号或替换新曲目媒体。

在线收藏保存稳定来源/实体身份和非敏感元数据，不写入本地 `library.json`，不把在线 ID 当文件路径。
插件缺失时保留收藏与回退信息；恢复后按原身份重新解析，不按歌曲标题猜测对应内容。
签名 URL、请求头、Cookie 和 Token 留在后端/隔离登录环境及受控凭据存储，主 WebView 只消费安全投影。
通用媒体调度仍由播放器负责：切歌更新全屏内容，视频与音频共享播放意图和进度，退出或失败释放对应资源。

同进程可信插件不是恶意代码沙箱；SHA-256 校验不能认证发布者，加载上下文也不能保证隔离原生崩溃。
以上是宿主接口和生命周期约束，不代表可安全运行任意不可信 DLL。

## 完成条件与验证证据

公开核心可独立构建只是其中一项，不能据此宣称插件的实际功能保持不变。

| 要求 | 应取得的证据 |
| --- | --- |
| 无平台硬编码与私人依赖 | 审阅主程序及全部随包组件的实现/资源/构建输入；在不含私人源码的独立树构建与发布 |
| 功能由插件声明驱动 | 任意来源 ID、无插件、缺能力/设置、旧包、移除/重启与迟到结果的 Host 和 UI 回归 |
| 管理页可用且一致 | 批量/拖入、错误与取消、默认关闭、启用、重启及清理失败反馈；键盘、深浅色和减少动画 |
| 原有体验保持 | 每个实际插件验证登录/续期、搜索分页、收藏封面、歌词、评论/媒体扩展与音视频切换；只验证其声明的能力 |
| 本地优先与 Windows 行为 | 无在线插件时的本地库/播放、空库、托盘/单实例/媒体键及真实 DPI、窗口模式检查 |
| 可公开交付 | 候选内容、测试数据和素材来源审阅；不带私人 Git 历史、用户状态、私有 DLL 或签名私钥 |

SDK 自检与合成 HTTP/凭据夹具不证明真实账号有效或平台在线；浏览器渲染比例不替代 Windows 跨屏 DPI。
截图能验证可见画面和状态，不能单独证明声音连续性、无双声、音画同步或逐帧动画流畅。
测试账号登录、信任确认及真实凭据删除应由用户参与，不能为了验收自动修改其账号或批准记录。
每次报告须区分已验证、失败、未覆盖及环境阻碍，不能把某个插件或单曲成功扩大为全部通过。

## 贡献与发布

构建和测试入口见仓库 README.md 与 AGENTS.md；插件作者指南见[插件分离说明](PLUGIN_SEPARATION.md)。
设置、凭据、兼容和 UI 的详细约束分别见[声明设置](PLUGIN_SETTINGS.md)、[凭据声明](PLUGIN_CREDENTIALS.md)、
[兼容性](PLUGIN_COMPATIBILITY.md)与[界面规范](UI_AND_INTERACTION.md)。

源代码公开与二进制发行是不同门槛。公开源码仍需素材和依赖审阅；分发解码库的二进制还需核对相应许可、
声明及对应源码要求。自签名测试包不代表受 Windows 信任的生产身份。插件化不豁免平台规则或内容访问权限。
推送仓库、改变可见性、签名或发布安装包需要明确授权，不由导出或自检自动执行。
