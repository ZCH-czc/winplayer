# Auralis 0.16.12 — Modular pages and reviewed updates

Pre-release for controlled testing. Application 0.16.12; MSIX 0.16.12.0; Windows x64.
The upgrade identity remains `Auralis.Player` / `CN=Auralis`.

## What's new

- A shared Fluent page renderer for optional modules: full-content pages, tabs, read-only search forms,
  responsive cards, galleries, nested discussions, and explicit media/queue actions.
- Module-owned bilingual settings groups and conditional choices. Missing modules do not create fake settings.
- Import review shows the selected and candidate versions, host compatibility and declaration changes.
  Confirmation rechecks both the candidate payload and the original review baseline.
- Choose a compatible older package for explicit reimport. Each revision requires trust approval,
  defaults to disabled, and takes effect after enabling and restarting. This is not automatic rollback or hot swapping.
- More robust next-track preparation with bounded waiting, cancellation and settings/account revision invalidation.
- Keyboard/focus improvements, high-scaling import-layout correction and cancellation of late import previews.

The core MSIX contains no concrete platform implementations or pre-enabled optional modules.
Host SDK 2.10 / Abstractions 1.11 supports new pages, settings and queries within the existing contract
without rebuilding the player. New operating-system capabilities still require host support.

## Installation and trust

Download the MSIX, its SHA-256 file and matching public CER from this Release. Keep your existing library and
settings; uninstalling or deleting user data is not an upgrade step. Quit the running player before upgrading.

This package uses the existing **self-signed development certificate**, not a publicly trusted production
signing chain. Installing it requires explicitly trusting that publisher through the normal Windows process.
Do not disable Windows security protections. No private signing key is distributed.

## Verification scope

Build, core/Host/contract tests, package boundaries, fixed-host module upgrade checks and isolated Web UI
checks are recorded in the [release acceptance notes](https://github.com/ZCH-czc/winplayer/blob/main/docs/releases/v0.16.12-acceptance.md). Automated browser projections are not a claim of actual
Windows cross-monitor DPI, native picker/restart, real-account or acoustic acceptance. External services may
be unavailable independently of package compatibility. This pre-release is not production certification.

Known limitation: default temporary-directory cleanup assertions intermittently observed a disappearing file entry;
dedicated-directory tests passed, but the intermittency is not resolved. Full native/live delivery gates remain incomplete.
