# Auralis 0.16.11 — Creator capabilities and next-track preparation

Controlled-test package, 2026-09-13. Application 0.16.11; MSIX 0.16.11.0.
Identity remains Auralis.Player, publisher CN=Auralis, architecture x64.

- Host SDK 2.2.0 / Abstractions 1.4.0 adds optional creator profiles, activity feeds and comment threads.
- Profile, feed and nested comments are independently declared; absent capabilities do not create UI.
- Fluent creator panels, dates, avatars, thread pagination, keyboard and reduced-motion handling.
- Plugin-aware next-track preparation: bounded foreground join, asynchronous cancellation/cleanup,
  settings/account revision invalidation and authorization-specific cache identity.
- The core package does not bundle concrete platform plugins. Import trusted matching packages separately.

Uses the existing development signing identity for an in-place upgrade from 0.16.10.0.
No uninstall or user-data reset is required. The self-signed certificate is for controlled testing,
not a Windows-trusted public production identity. Packaging does not install or publish.

## 简体中文

本测试版解决旧核心不能导入新能力插件的问题，插件宿主升级为 SDK 2.2.0。
应用版本与 MSIX 版本同步递增，保持应用身份和发布者不变，可覆盖升级。
核心仍不附带具体平台插件；升级后再导入、启用对应插件并重启。
真实平台账号、原生 DPI 和听感验收不由静态契约检查代替。
