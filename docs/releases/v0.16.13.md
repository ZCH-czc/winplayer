# Auralis 0.16.13 — Refined plugin reading and search

Pre-release for controlled testing. Application 0.16.13; MSIX 0.16.13.0; Windows x64. The upgrade identity remains `Auralis.Player` / `CN=Auralis`.

## Player and interface

- Long, truncated video titles reveal their full text in a pointer-positioned and keyboard-accessible bubble.
- Plugin search can show public video play counts in place of a redundant source column. Co-published works retain their primary author link without incorrectly assigning that link to every collaborator.
- Plugin reading pages now show public like/repost counts, keep the discussion heading in place while comments scroll, and continue loading bounded comment pages as the reader approaches the end.
- Short-lived, bounded page caching reduces unnecessary fetches when returning to a page. Explicit refresh still bypasses the cache.
- Dynamic-page loading and the all-activity filter use quieter Fluent-style transitions and reduced-motion fallbacks.

The player core still builds and runs without optional provider plugins. No concrete provider or account is included in the core package.

## Plugin contract

Host SDK 2.15.0 and Abstractions 1.16.0 add an optional public-metrics contract. Older hosts reject incompatible newer plugins rather than failing only after activation. Optional modules are distributed separately; import, review, trust, enable and restart remain explicit user actions.

## Testing and trust

Release build, core and host tests, isolated light/dark Web UI checks, and plugin-boundary checks were run. Browser fixtures use synthetic data. They do not establish real-account access, native audio/video playback, or every Windows DPI configuration.

The MSIX is signed with the existing self-signed **development** certificate. It is not a publicly trusted production signature. Verify the SHA-256 attachment and the matching public CER before controlled installation; do not disable Windows security protections. No private key is distributed.
