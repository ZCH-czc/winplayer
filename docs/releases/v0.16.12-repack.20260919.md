# Auralis 0.16.12 — IDE workspace and September test repack

Controlled-test **pre-release**, Windows x64 (Windows 10 build 19041 or newer).

## Source workspace

- New `Auralis.Development.sln`: 32 grouped projects for the player, components, contracts, tests,
  SDK sample and diagnostic tools. Compatible with the classic Visual Studio solution format.

  diagnostic execution and explicitly configured frozen-SDK tools.

## Verification scope

The packaging pass verified the signed MSIX, hashes, actual published core boundary, Release build,
core/Host regressions and 89 contract-tool checks. It did not install the package into the user's profile.
The new IDE solution is additionally build-checked; no runtime, UI or Native/Web protocol change is claimed.
Fresh installed-app audio, physical cross-monitor DPI and full native acceptance are not established by
these checks. This is a controlled-test distribution, not stable-production certification.

The **2026-09-19 clean-source rerun** reproduced the previously recorded intermittent media-cache cleanup
assertion in `Auralis.Tests` (enumeration reported one `.tmp` entry; probing it returned FileNotFound).
That run failed and is **not** reported as passed or cleared by an automatic retry. It differs from the
successful September 17 packaging run above. No runtime fix is claimed in this IDE-only change.
The 32-project development solution builds with zero warnings/errors; the updated isolated login
diagnostic passes 11 synthetic WPF lifecycle scenarios, not real account login.
