# Auralis 0.16.10 — Showcase and distribution maintenance

This release captures the current English-first overview, bilingual documentation
and interactive Fluent player showcase at https://zch-czc.github.io/winplayer/.

- Automatic light/dark full-screen player demonstration and record rotation.
- Screenshot carousels for artwork layouts, queue and lyric panels.
- Five accent selections paired with matching UI screenshots.
- Chinese artwork and LRC presentation; the standalone song playback card is removed.
- Silent visual demonstrations with pause, reduced-motion and hidden-view handling.
- Normalized two LRC line endings so guarded downstream synchronization can proceed.

The player runtime logic and component contracts are unchanged from 0.16.9.
The promotional website is not bundled into the desktop application.
Application version: **0.16.10**; MSIX version: **0.16.10.0**.
Package identity remains `Auralis.Player`, publisher `CN=Auralis`, Windows x64.
The version increment allows a separately rebuilt controlled-test package to upgrade
0.16.9 without overwriting a previously released asset or changing the old tag.

## Public source preview

The public Release contains source only, without optional platform implementations,
an installer or a development certificate. Trusted production signing and the exact
native dependency notice/corresponding-source review remain prerequisites for public
binary distribution. Third-party promotional media retain their documented ownership
and permission; they are not covered by the source's MIT license.
