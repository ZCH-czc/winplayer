# Auralis 0.16.9

This maintenance update fixes a timeout race discovered during clean Windows CI
acceptance. A timed-out optional lyric lookup now ends the lookup instead of
starting another candidate while the shared budget timer is still pending.
Local lyrics and local playback do not depend on this optional lookup.

The regression fixture reproduces the ordering deterministically, without
sleeping until a probabilistic race occurs. The existing total-budget and caller
cancellation checks remain in place. Neither the timeout nor a failed check is
ignored or retried until success.

Application version: 0.16.9. MSIX version: 0.16.9.0.
The Auralis.Player / CN=Auralis package identity and component contracts are
unchanged. This source update does not install or enable any optional components.

The public distribution remains a source preview. Trusted production signing
and the exact native dependency notice/corresponding-source review are still
required before public binary distribution.
