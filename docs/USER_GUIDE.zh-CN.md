# Auralis 使用指南

[返回中文首页](../README.zh-CN.md) · [English](USER_GUIDE.en-US.md)

## 整理本地音乐

在“歌曲”页使用“添加音乐”，或通过音乐文件夹设置维护曲库。随后可以按歌曲、专辑和艺术家浏览，也可以搜索曲目。

“我喜欢的”便于保留常听曲目；“最近播放”帮助你找回刚听过的内容。“我的歌单”用于按自己的习惯组织曲目。

![本地曲库界面演示](screenshots/library-zh-CN.png)

*演示曲库展示歌曲信息与常驻播放栏；标题、封面和音质值均为文档示例。*

## 使用播放页

点击底部当前曲目信息，进入展开的播放页。可使用播放/暂停、上一首/下一首、进度、音量和播放模式控制；右侧队列在当前播放页内展开。

在“设置 → 全屏播放器”选择“沉浸封面”或“唱片与歌词”。前者突出专辑封面，后者把歌词与唱片视觉并列呈现。应用内播放页与 Windows 全屏模式是不同状态；F11 控制窗口全屏。

![深色唱片与歌词布局演示](screenshots/player-zh-CN.png)

*此图是暂停状态的界面演示，不是动态效果或音频输出测试。*

## 调整外观与歌词

- 在外观设置选择浅色、深色或跟随系统。
- 在全屏播放器设置中调整布局、背景、封面过渡和歌词表现。
- 使用设置页的可视化预览查看配置结果；预览本身不会播放音频。
- 对动效敏感时使用减少动画偏好。
- 有同步时间标记的 LRC 文件可跟随播放进度显示；行级歌词高亮不等同于逐字时间戳。
- 需要常驻文字时，可在设置中配置桌面歌词。

![播放页设置预览](screenshots/customize-zh-CN.png)

*预览展示同一套布局与主题偏好，便于比较后再回到播放页。*

## 查看音质

播放栏与全屏播放器共用当前音质信息。码率可获得时显示在标签上；悬停可查看更多格式参数。

FLAC 的“≈”表示平均编码码率。采样率使用 kHz，位深使用 bit，声道数使用 ch。不是所有媒体或播放组件都能提供完整信息；缺失数据不表示音质降低。

## 管理扩展组件

默认播放后端随软件提供，普通播放不需要额外安装组件。

如确有需要，可以在设置中的插件管理页展开“高级组件”，使用播放组件的专用导入入口。只导入可信且兼容的包，检查名称、版本及能力，主动确认信任，再启用并重启。重启会停止当前播放。

组件包类型不能混用：播放组件使用专用的 `.auralis-playback.zip` 包；其它包应走对应入口。插件运行于播放器进程，不是安全沙箱；完整性校验不能替代对来源的信任。当前没有图形卸载/回滚入口。

## 快捷操作和常见问题

- 可用 Tab / Shift+Tab 移动焦点，Enter / Space 操作具有焦点的按钮。
- 播放快捷键可在播放设置中查看和调整；Windows 媒体键也可控制播放。
- 找不到歌词时，检查本地 LRC/TXT 文件，或从当前歌曲的歌词选项中选择文件。
- 音频无声时，先检查系统与应用音量，再检查输出设备。
- 系统不支持云母材质时会使用实色回退，这不影响基本播放。
- 关闭窗口是否退出应用取决于托盘设置；需要完全退出时使用托盘退出操作。
